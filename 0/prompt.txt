Create Your First Agent
After every push, Entire Agents will review the code changes and evaluate confidence levels through different customizable monitors, such as Confidence, Risk, Security, and Drift. Navigate to your project on entire.com:

    Open your project and go to Agents.
    You can start from a list of preset agents and click Enable as is: Or, click New agent and customize the agent to your own needs:
    Under Agent, give it a name and description. Pick the harness, model, reasoning effort and timeout, and write its Instructions (what it should review). Then set the signal it reports: a value type and a polarity.
    Under Trigger, choose when it runs, for example Trail branch pushed, Run manually or Recurring schedule.
    Under Repositories, select at least one repository.
    Leave the toggle on Active and click Create agent.

Each of these agents produces an evaluation score and can flag what needs fixing as Findings.
